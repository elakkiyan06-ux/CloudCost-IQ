1. Cost Calculation Formulas

• Hourly Resource Cost: unit_price × quantity (for hourly billing units)
• Monthly Compute Cost: hourly_rate × quantity × scheduled_usage_hours (e.g. 730h 24/7 or 174h 8x5)
• Non-Hourly Storage / Ingestion Cost: unit_price × quantity (e.g. $0.0800 × GB stored/mo)
• Total Monthly Cost: ∑ (monthly_resource_costs)
• Estimated Annual Cost: total_monthly_cost × 12
• Absolute Savings: baseline_cost (Config A) − alternative_cost (Config B)
• Percentage Savings: (savings ÷ baseline_cost) × 100 (when baseline > 0)

2. Complete AWS EC2 Ubuntu Deployment Walkthrough

  1. Launch Ubuntu 24.04 LTS Instance: Select instance type t4g.small (or t3.micro / t3.small) with 20 GB gp3 root storage.
  2. Configure Security Group Inbound Rules:
    • Port 22 (SSH) restricted to your administrative IP.
    • Port 80 (HTTP) open to 0.0.0.0/0 for public access.
    • Port 443 (HTTPS) open to 0.0.0.0/0 for TLS certificate renewal.
  3. Connect and Install Docker & Docker Compose: 
    sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
  4. Clone Repository & Launch with Docker Compose: 
    git clone <your-repo-url> cloudcost-iq && cd cloudcost-iq
docker compose up -d --build
curl -f http://localhost/api/health
  5. Attach Domain and Configure HTTPS (Certbot Let's Encrypt): 
    sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com

3. GitHub Actions CI/CD Pipeline

The repository includes an automated continuous integration and continuous deployment workflow in .github/workflows/deploy.yml. On every push to main, GitHub Actions automatically:

  • Sets up Python and installs test dependencies.
  • Runs the comprehensive pytest test suite (29 tests) verifying calculator accuracy, edge cases, and API routes.
  • Validates pricing dataset schema and integrity.
  • Builds the Docker container images.
  • Deploys via SSH to the target AWS EC2 VM using repository secrets (DEPLOY_HOST, DEPLOY_USER, DEPLOY_SSH_KEY).
  • Executes an automated post-deployment health check on /api/health.
